# Правила для агента: BSL / 1С

Проект: конфигурация 1С в формате выгрузки EDT (`src/`). Отвечай на русском, без emoji.

## Запросы и данные
- Запрос к базе в цикле запрещён. Собирай данные одним запросом (`В (&Массив)`, временная таблица, соединение).
- Не используй обращение к реквизитам через точку от ссылок в цикле: это скрытый запрос.
- В запросах указывай только нужные поля, `ПЕРВЫЕ N` вместе с `УПОРЯДОЧИТЬ ПО`.

## Транзакции и исключения
- `НачатьТранзакцию()` всегда внутри `Попытка`, в `Исключение` обязательна `ОтменитьТранзакцию()`.
- Пустой блок `Исключение` запрещён: логируй через `ЗаписьЖурналаРегистрации` и/или `ВызватьИсключение`.
- Текст ошибки пиши через `ПодробноеПредставлениеОшибки(ИнформацияОбОшибке())`.

## Клиент и сервер
- Не вызывай сервер в цикле на клиенте. Передавай данные пакетом одним серверным вызовом.
- Серверный вызов из клиентской процедуры делай через `&НаСервере` или `&НаСервереБезКонтекста`.

## Безопасность
- Пароли, токены и строки подключения не хранятся в коде. Используй константы и безопасное хранилище.

## Стиль
- Экспортные методы имеют комментарий: назначение, `Параметры:`, `Возвращаемое значение:`.
- Имена: русские, каждое слово с заглавной буквы (`СуммаДокумента`), без сокращений и транслита.
- Метод короче 50 строк. Закомментированный код не оставляй.
- Отступы табуляцией, области `#Область ... #КонецОбласти`.

## Работа с кодом
- Меняй только то, что просит задача. Не форматируй чужой код.
- Правки в PR фиксируй отдельным коммитом с понятным русским описанием.
- Git используй только на чтение, если задача не требует иного.
